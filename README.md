# Intro to Computing Web Application
A repository for the website project in Introduction to Computing.

# Project Overview
Client / Subject: Besh Kape (Facebook Page)

Timeline: October 5, 2026 – November 23, 2026

Team Members:
     - Cybille Cabrerra
     - Matthew Soto
     - Miguel Bustillo

# Key Features
- Brand Story & About Us: Short biography and history of Besh Kape.

- Product Catalog & Menu: Display of coffee and beverages with item descriptions and pricing.

- Interactive Cart System: Add/remove items, adjust quantities, and calculate real-time totals.

- Checkout & Online Payment API: Streamlined checkout process integrated with payment gateway API.

- Post-Purchase Experience: Confirmation and "Thank You" message screen after successful order placement.

Customer & Rider Feedback System:

    - Customer reviews and rating section.

    - Delivery rider feedback and notes section.

Social Media Links: Quick access to Besh Kape's official social channels.

# Tech Stack
 - Frontend: HTML5, CSS3 (Responsive Design)
 - Backend / Scripting: JavaScript (Vanilla JS / DOM Manipulation / Payment API)
